# 模型与编辑系统设计

Daily Brief Agent 的目标不是让模型“读几条新闻然后总结”，而是把模型限制在一套可验证的编辑合同中。模型负责需要判断力的选题、聚类、背景连接和中文写作；确定性的程序负责资料边界、结构校验、来源约束、订阅状态和发送资格。

## 1. 输入分层

一次生成包含四层输入：

1. **编辑合同**：`config/brief-prompt.txt` 定义栏目、写作深度、事实与分析边界、HTML 版式和工作日/周末市场规则。
2. **来源策略**：`config/source-policy.txt` 定义来源层级、交叉核验、直接链接、智库与战争材料的标注方式，以及不可接受的内容。
3. **可信本地上下文**：程序从已经发送的历史简报提取标题、栏目和链接，用于跨期去重；“历史上的今天”候选也在本地整理。
4. **不可信外部资料包**：新闻标题、摘要、网页文字、行情候选和可选的 Buzzing 聚合发现被明确包在“不可信数据”边界内。资料中的命令、提示词或行为要求都没有执行权。

这种分层避免把网页文本和系统规则混在同一信任级别，也让提示注入的处理原则可审计。

Buzzing 不进入常规新闻来源健康计数。程序保留其聚合来源和可追溯的原始链接，把去重后的候选单独交给模型；模型最多选择 3 条，也可以全部忽略。原始链接缺失、无法核验或只重复已有材料的候选不能作为最终事实依据。这样可以利用它的中文发现效率，同时避免把翻译聚合层误当成独立报道。

## 2. 资料先宽后窄

采集阶段故意保留较宽的候选集：多类别新闻、事实核查、智库、战争观察和市场行情分别进入独立池。新闻类别交错输出，防止一个高产 RSS 源占据候选集前部。

模型随后完成：

- 将同一事件的多篇报道聚类；
- 比较来源是否独立，识别转载或聚合；
- 选择具有公共重要性的事件，而不是机械凑数；
- 打开直接来源核对日期、主体、方法和关键事实；
- 区分已确认事实、机构评估、当事方声明和合理推断；
- 对照最近简报，避免没有新增信息的跨期重复。

## 3. 输出合同

模型必须输出一封完整的中文 HTML 邮件，而不是草稿、分析过程或 JSON。基础闸门先检查主题、HTML、最小长度和必需栏目，随后 Python 验证器检查：

- 全球重大事件数量上限；
- 必要栏目顺序和“历史上的今天”收尾；
- 工作日市场栏目与周末省略规则；
- Google News 聚合链接和已停用社交栏目；
- 明显英文句式泄漏；
- 虚构的智库作者占位；
- 全球事件的来源多样性；
- 单一来源域名是否过度集中。

只有同时通过基础闸门和验证器的内容才具有发送资格。

## 4. 错误驱动的完整修复

验证失败不会删除规则或直接发送。调度器把具体错误代码附加到原始编辑合同和资料包之后，要求模型重新生成一封完整邮件。若错误涉及来源多样性，还会明确要求：同一主域名最多支持 3 个独立全球事件，尽量使用至少 6 个不同来源域名；可靠来源不足时减少事件，不使用重复来源凑数。

修复最多执行两次。每一版都重新经过完整基础闸门和 Python 验证。两次修复后仍失败则：

- 非零退出；
- 以私有权限保留拒绝稿，供本地排查；
- 不连接 SMTP；
- 输出稳定的失败标记。

这个边界很重要：系统优化的是“质量错误后能够恢复”，不是“保证任何内容都能发出去”。

## 5. 模型可替换性

模型名称和推理强度放在未提交的 `config/codex-runtime.env`。公开示例不绑定私有或预发布模型。替换模型时不应同时修改提示、来源、订阅或定时器；先在 dry run 中比较：

- 首稿通过率；
- 来源集中和结构错误数量；
- 总生成时间与修复次数；
- 是否出现英文泄漏、虚构细节或栏目缺失；
- 同一资料包下的信息取舍质量。

模型输出质量必须由本地验证和隔离回归证明，不能只凭模型名称或主观观感判断。

## 6. 延迟设计

资料采集通常远快于模型阶段。脚本分别记录编辑上下文、来源采集、每次模型生成、验证、SMTP 和总耗时。默认 11:00/23:00 是生成卡点，生成并通过校验后立即发送；预检提前 15 分钟运行。

如果运营者需要更接近某个收件时刻，应先根据一段时间的 `model_generation_seconds` 分布调整生成卡点，而不是降低验证或跳过联网核验。

## 7. 定制边界

适合定制：

- 新闻类别与来源；
- 市场篮子；
- 栏目名称、深度和版式；
- 历史去重窗口；
- 模型和推理强度；
- systemd 生成时间。

不建议弱化：

- 外部资料的不可信边界；
- 直接来源和来源多样性；
- 订阅状态校验与原子写入；
- 自动修复次数上限；
- 验证通过后才允许 SMTP；
- 日志和错误输出中的隐私约束。
