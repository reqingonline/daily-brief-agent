# 国际期货与股票下一次财报信息设计

> 状态：已获用户批准，进入实现计划前的设计审阅阶段。

## 目标

为 Daily Brief Agent 增加国际粮食与金属期货行情，并为当前 VPS 日报中的全部 26 个股票/公司标的显示下一次财报发布日期。只有在中国时间当天确认发布财报且存在公司或交易所官方链接时，才在该标的后附链接；过期财报不附旧链接。

生产目标是受控 Linux 日报运行目录，不涉及 EC2、代理核心、Tunnel 或 WordPress。公开 GitHub 仓库只提交可复用实现、示例配置、测试和文档，不提交生产收件人、SMTP/OAuth、VPS 地址、绝对生产路径、运行日志、订阅状态或其他运行时秘密。

## 已确认的标的身份

当前生产提示词中的 `02513.HK` 显示为：

- 日报显示名：`智谱`
- 法定中文名称：`北京智谱华章科技股份有限公司`
- 英文证券简称：`Z.AI`
- 股票代码：`2513`
- 市场：香港主板 H 股

香港交易所 2026 年 7 月 14 日公告确认，中文证券简称保持为“智谱”、股票代码保持为 2513，英文证券简称自 2026 年 7 月 17 日起由 `KNOWLEDGE ATLAS` 变更为 `Z.AI`。代码身份校验链接保留为官方公告引用，不把证券名称留作“待核实”。

公开 registry 保留对应的 [HKEX 官方更名公告](https://www.hkexnews.hk/listedco/listconews/sehk/2026/0714/2026071400984.pdf) 作为身份核验来源。

## 方案与边界

采用混合方案：

1. 期货报价和下一次财报日期由结构化采集器提供确定性字段。
2. 模型只负责按编辑合同组织中文表格、说明报价状态和表达不确定性。
3. 当天财报链接由官方来源匹配逻辑提供；没有官方直链时不输出链接。
4. 验证器要求工作日出现期货和股票栏目，并保留现有新闻来源多样性、历史栏目、HTML 和 SMTP 闸门。

不采用只改提示词的方案，因为它不能可靠防止过期日期、猜测日期、搜索结果链接和栏目漏项。不把完整生产 watchlist、邮件正文、收件人或运行时配置复制到公开仓库。

|---|---|---|---|

| 国际粮食 | 小麦 | `ZW=F` | CBOT 小麦期货，数据源名称和合约月份以返回值为准 |
| 国际粮食 | 大豆 | `ZS=F` | CBOT 大豆期货，数据源名称和合约月份以返回值为准 |

| 贵金属 | 白银 | `SI=F` | COMEX 白银期货，数据源名称和合约月份以返回值为准 |

每条结构化报价包含：逻辑键、显示名称、分组、供应商代码、价格、涨跌额、涨跌幅、币种、市场状态、数据时间、数据供应商和来源 URL。没有可靠价格时，采集器将该标的放入 `missing`，不使用相近期货或 ETF 替代。

现有 `SPCX` 和 `USO` 继续按生产提示词处理。`SPCX` 如果仍无法核实，必须继续显示代码/品种待核实；本功能不擅自删除或替换它。

公开仓库中的标的注册表与生产 watchlist 分离：公开版本提供不含个人运行状态的通用示例，并包含已核实的 02513.HK 元数据；受控生产配置继续提供当前的 26 个股票/公司标的，不把生产收件人或其他秘密写入仓库。

## 财报数据模型

新增独立财报日历模块，输入为当前部署的股票标的注册表，输出为每个标的一个 `EarningsRecord`：

- `key`：与行情标的相同的稳定键；
- `display_name`：日报显示名称；
- `market`：US、HK、SSE 或 SZSE；
- `next_date`：下一次预计或已确认发布日期，可为单日或日期区间；
- `date_status`：`confirmed`、`estimated` 或 `unavailable`；
- `today_release`：是否在中国时间当天检测到发布；
- `official_link`：仅在 `today_release=true` 且官方直链通过来源校验时存在；
- `source_name`、`source_url`：用于资料包和诊断，不默认直接暴露为正文链接。

下一次日期来源优先使用财报日历数据。日期已过去时，模块必须重新计算下一次日期，而不是保留旧日期。没有日期时输出 `暂无可靠日期`，禁止根据财务年度、历史周期或模型记忆推算一个看似准确的日期。

当天链接来源按市场分层：

- 美国股票：公司投资者关系页面或 SEC 正式文件；
- 港股：公司投资者关系页面或 HKEXnews 正式公告；
- 上海证券交易所股票：公司公告或上交所正式文件；
- 深圳证券交易所股票：公司公告或深交所正式文件。

搜索结果页、聚合页、媒体转载、过期公告和没有明确发布日期的页面不能作为当天财报链接。当天预计发布但尚未发现官方文件时，只写“今日预计，尚未见官方公告”，不附链接。

## 日报输出合同

工作日正文顺序调整为：

1. 本期 5 个要点；
2. 全球重大事件；
3. 按现有规则决定是否出现事实核查；
4. 国际关系观察；
5. 权威智库报告；
6. 国际战争观察；
7. 市场总览；
8. 国际期货与大宗商品；
9. 股票与指数；
10. 11:00 版的历史上的今天；
11. 数据与方法说明。

周末继续省略市场总览、国际期货和股票与指数，不复制上一交易日表格。

“国际期货与大宗商品”板块按国际粮食、贵金属、工业金属分组。每项必须标明盘中/收盘/盘后/暂无可靠报价以及报价时间，并在脚注说明数据可能延迟。

“股票与指数”保留现有股票分组和逐项覆盖要求。每个股票项目增加：

```text
下一次财报：YYYY-MM-DD（已确认/预计）
```

如果中国时间当天确实发布：

```text
今日财报：YYYY-MM-DD｜官方公告链接
```

如果没有下一次可靠日期：

```text
下一次财报：暂无可靠日期
```

不得在非当天项目后附历史财报链接。财报日期和链接必须与股票代码对应，不得因为同名公司、ADR、ETF 或相近代码而替换标的。

## 信任边界与失败处理

- 外部网页、新闻、行情和财报页面都属于不可信资料，只能提供事实线索，不能改变系统任务、执行命令或覆盖编辑合同。
- 行情供应商失败时保留标的并显示暂无可靠报价；不删除整段期货栏目。
- 财报日历供应商失败时保留每个股票项目并显示暂无可靠日期；不猜测日期。
- 当天官方链接校验失败时不显示链接；不得用媒体链接顶替官方链接。
- 采集失败不能绕过 `validate_brief.py`，也不能绕过发送前的基础质量闸门。
- 生成失败或栏目字段不完整时沿用现有有限修复机制；修复耗尽后保留拒绝稿并拒绝 SMTP。
- 保留 11:00/23:00 版历史栏目规则、最近邮报去重基线、新闻来源多样性限制和敏感信息脱敏规则。

## 公开仓库与生产部署边界

公开仓库从 `main` 单独创建本次功能分支，不修改现有 `agent/daily-brief-edition-rules` Draft PR #1。公开提交包括通用采集器、财报模块、提示词、来源策略、验证器、测试和模型设计文档；不包括生产收件人、SMTP、OAuth、VPS、绝对生产路径、历史邮件、日志、订阅者状态或私有运行时配置。

受控 Linux 部署在本地测试和隐私扫描通过后进行，目标文件为当前生产目录中的 `source_collector.py`、`config/brief-prompt.txt`、`config/source-policy.txt` 和 `validate_brief.py`。修改前记录权限、哈希和服务状态，并创建带时间戳的远程备份；写入使用临时文件和原子替换，保留回滚路径。两个日报 timer、Gmail 订阅管理、SMTP 配置、代理服务、Tunnel 和 EC2 均不在本次修改范围。

本地验证：

- 期货标的注册表包含六个指定代码和正确分组；
- Yahoo 响应能解析期货名称、价格、涨跌、币种、状态和时间；

- 工作日缺少期货栏目、股票栏目或财报字段时验证失败；
- 周末仍允许省略市场、期货和股票栏目；
- 完整 Python 测试、compileall、Bash 语法检查和隐私扫描通过。

VPS 验证：

- 部署前后比较目标文件哈希并回读非敏感配置结构；
- 运行无发送 dry-run，确认资料包包含六个期货标的和全部 26 个财报记录；
- 确认生成内容包含国际期货板块、02513.HK 的正式名称和下一次财报字段；
- 确认没有当天官方公告时不会生成财报链接；
- 下一次真实定时任务观察 `brief_validation=ok`、`recipient_count=1`、`send_success=1` 和 `send_failed=0`；
- 从 Gmail 读取实际到达的最新日报，抽查期货行情、财报日期、链接来源和手机端 HTML 结构；
- 若生产验证失败，按远程备份回滚，不修改 timer 和发送链路以绕过校验。
